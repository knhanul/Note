# AI 기능 관리 사용자 매뉴얼

## 개요

AI 기능 관리는 사용자가 AI 기능을 등록, 수정, 삭제하고 프롬프트 문서와 연결할 수 있는 기능입니다. 이 매뉴얼은 AI 기능 관리의 각 구성 요소와 사용 방법을 설명합니다.

## 접근 방법

1. AI 패널에서 설정 버튼(⚙️) 클릭
2. AI 설정 팝업이 열리면 기본으로 "모델 설정" 탭이 표시됩니다
3. "AI 기능 관리" 탭을 클릭하여 AI 기능 관리 화면으로 이동

## AI 기능 관리 화면 구성

### 1. 기능 목록 (왼쪽 패널)

등록된 모든 AI 기능이 목록으로 표시됩니다. 기능을 클릭하면 상세 정보를 볼 수 있습니다.

- **기능 목록**: 등록된 AI 기능 목록
- **선택**: 기능을 클릭하여 상세 정보 확인

### 2. 기능 상세 (오른쪽 패널)

선택한 AI 기능의 상세 정보를 표시하고 수정할 수 있습니다.

#### 기능 정보
- **기능명**: AI 기능의 이름 (수정 시 변경 불가)
- **설명**: 기능에 대한 설명

#### 연결된 프롬프트
- AI 기능에 연결된 프롬프트 문서를 선택/변경할 수 있습니다
- 드롭다운에서 프롬프트를 선택하여 연결

#### 기능 설정
- **카테고리**: 기능 분류
- **입력 모드**: 기능 실행에 필요한 입력 유형
- **RAG 사용**: 문서 검색 기능 사용 여부
- **필수 변수**: 기능 실행에 필요한 추가 변수

### 3. AI 기능 추가 버튼

화면 상단의 "+ AI 기능 추가" 버튼을 클릭하여 새로운 AI 기능을 등록할 수 있습니다.

## AI 기능 등록

### 등록 필드 설명

#### 기능 이름
- **용도**: AI 기능의 이름
- **필수**: 필수 입력
- **자동 생성**: 기능 ID는 기능 이름을 기반으로 자동 생성됩니다

#### 설명
- **용도**: 기능에 대한 설명
- **필수**: 선택 사항

#### 연결할 프롬프트
- **용도**: 이 기능에 연결할 프롬프트 문서 선택
- **필수**: 선택 사항
- **참고**: AI 프롬프트 서재에 등록된 모든 프롬프트가 표시됩니다

#### 카테고리
- **용도**: AI 기능을 분류하는 그룹
- **옵션**:
  - `user`: 사용자 정의
  - `문서 처리`: 문서 관련 기능
  - `문서 질문`: 문서 질문 기능
  - `기타`: 기타 기능
- **필수**: 선택 사항

#### 입력 모드
- **용도**: AI 기능 실행에 필요한 입력 유형 정의
- **옵션**:
  - `auto`: 자동으로 입력 결정
  - `note_required`: 노트가 필수 (노트를 선택해야 함)
  - `chat_only`: 채팅만 가능 (노트 없이 채팅만으로 실행)
  - `note_and_chat`: 노트와 채팅 모두 필요
  - `selection_required`: 선택문장 필요 (노트에서 텍스트를 선택해야 함)
- **필수**: 선택 사항

#### RAG(문서 검색) 사용
- **용도**: Retrieval-Augmented Generation 사용 여부
- **설명**:
  - `체크`: AI가 관련 문서를 검색해서 답변 생성
  - `체크 해제`: 문서 검색 없이 답변 생성
- **활용**: 문서 질문 기능에서 유용
- **필수**: 선택 사항

#### 필수 변수 (JSON)
- **용도**: AI 기능 실행에 필요한 추가 변수 정의
- **형식**: JSON 배열
- **예시**: `["user_name", "department"]`
- **활용**: 프롬프트 템플릿에서 변수로 사용
- **기본값**: `[]` (필수 변수 없음)
- **필수**: 선택 사항

### 등록 절차

1. "+ AI 기능 추가" 버튼 클릭
2. 기능 이름 입력 (필수)
3. 설명 입력 (선택)
4. 연결할 프롬프트 선택 (선택)
5. 카테고리 선택 (선택)
6. 입력 모드 선택 (선택)
7. RAG 사용 여부 선택 (선택)
8. 필수 변수 입력 (선택)
9. "등록" 버튼 클릭

## AI 기능 수정

### 수정 가능 필드

- **설명**: 기능 설명 수정
- **연결된 프롬프트**: 프롬프트 연결 변경
- **카테고리**: 카테고리 변경
- **입력 모드**: 입력 모드 변경
- **RAG 사용**: RAG 사용 여부 변경
- **필수 변수**: 필수 변수 변경

### 수정 불가 필드

- **기능명**: 기능 ID와 연결되어 있어 수정 불가

### 수정 절차

1. 기능 목록에서 수정할 기능 선택
2. "수정" 버튼 클릭
3. 수정 가능한 필드 변경
4. "저장" 버튼 클릭

## AI 기능 삭제

### 삭제 절차

1. 기능 목록에서 삭제할 기능 선택
2. "삭제" 버튼 클릭
3. 삭제 확인 대화상자에서 확인

### 주의사항

- 삭제된 기능은 복구할 수 없습니다
- 삭제 전 연결된 프롬프트를 확인하세요

## 프롬프트 연결

### 연결 방법

1. 기능 등록 시: "연결할 프롬프트" 드롭다운에서 선택
2. 기능 수정 시: "연결된 프롬프트" 드롭다운에서 변경
3. 기능 상세 보기: "연결된 프롬프트" 드롭다운에서 변경

### 프롬프트 목록

- AI 프롬프트 서재에 등록된 모든 프롬프트가 표시됩니다
- 프롬프트 제목으로 식별됩니다

## 사용 예시

### 예시 1: 문서 요약 기능 등록

```
기능 이름: 문서 요약
설명: 선택한 노트의 내용을 요약합니다
연결할 프롬프트: summarize_note
카테고리: 문서 처리
입력 모드: selection_required
RAG 사용: 체크
필수 변수: []
```

### 예시 2: 할 일 추출 기능 등록

```
기능 이름: 할 일 추출
설명: 노트에서 할 일 목록을 추출합니다
연결할 프롬프트: extract_todo
카테고리: 문서 처리
입력 모드: note_required
RAG 사용: 체크 해제
필수 변수: []
```

### 예시 3: 문서 질문 기능 등록

```
기능 이름: 문서 질문
설명: 노트 내용에 대해 질문하고 답변을 받습니다
연결할 프롬프트: current_note_qa
카테고리: 문서 질문
입력 모드: note_and_chat
RAG 사용: 체크
필수 변수: []
```

## 주의사항

1. **기능 ID**: 기능 ID는 기능 이름을 기반으로 자동 생성되며 수정할 수 없습니다
2. **프롬프트 연결**: 프롬프트를 연결하지 않으면 기능이 정상적으로 동작하지 않을 수 있습니다
3. **필수 변수**: JSON 형식이 올바른지 확인하세요
4. **삭제**: 삭제된 기능은 복구할 수 없습니다

## 문제 해결

### 프롬프트가 표시되지 않음

- AI 프롬프트 서재에 프롬프트가 등록되어 있는지 확인
- 프롬프트가 활성화되어 있는지 확인

### 기능 등록 실패

- 기능 이름이 입력되었는지 확인
- 필수 변수 JSON 형식이 올바른지 확인

### 기능 수정 실패

- 필수 변수 JSON 형식이 올바른지 확인
- 연결할 프롬프트가 유효한지 확인

## 기술 정보

### 파일 위치

- **QML**: `qml/components/AIActionManagementPanel.qml`
- **QML**: `qml/components/AISettingsDialog.qml`
- **Python**: `packages/ollama_plugin/ai_action_controller.py`

### 데이터 저장

- AI 기능 데이터는 `app_data/ai/` 디렉토리에 저장됩니다
- 프롬프트 연결 정보는 AI 기능 데이터에 포함됩니다

## 참고

- AI 기능 관리는 `work_ai_editor` 앱에서만 활성화됩니다
- 프롬프트 관리는 AI 프롬프트 서재에서 별도로 수행합니다
