# 참고문서AI 답변방식별 프롬프트 문서

이 문서는 현재 구현된 참고문서AI(RAG)의 답변방식별 프롬프트를 설명합니다.

## 개요

참고문서AI는 사용자가 등록한 참고문서를 검색하여 질문에 답변하는 기능입니다. 현재 두 가지 답변방식이 제공됩니다.

---

## 1. 참고문서 질문 답변 (rag_qa)

### 기본 정보
- **action_id**: `rag_qa`
- **prompt_doc_id**: `rag_qa`
- **카테고리**: 참고문서 RAG
- **입력 모드**: `rag_question`
- **사용 범위**: `reference_rag`
- **필요 변수**: `USER_INPUT`, `RAG_CONTEXT`

### 역할
검색된 참고문서 내용만 근거로 질문에 답하는 RAG 문서 분석 도우미

### 작업
사용자 질문에 대해 검색된 참고문서에서 확인되는 내용만 사용해 답변

### 출력 형식
```markdown
### 답변
-

### 근거
-
-

### 제공된 참고문서에서 확인할 수 없는 내용
-
```

### 반드시 지킬 규칙
- 검색된 참고문서에 없는 내용은 답하지 마세요.
- 외부 지식을 사용하지 마세요.
- 근거가 없으면 "제공된 참고문서에서는 확인할 수 없습니다."라고 답하세요.
- 참고문서 간 내용이 다르면 "문서 간 내용이 다릅니다."라고 표시하세요.
- 질문과 관련 없는 참고문서 내용은 제외하세요.

### 사용 예시
- **예시 입력**: "요금과 관련된 내용을 찾아서 알려줘"
- **입력창 안내**: "예: 참고문서에서 확인되는 내용만 답변해줘"

---

## 2. 참고문서 근거만 정리 (rag_evidence)

### 기본 정보
- **action_id**: `rag_evidence`
- **prompt_doc_id**: `rag_evidence`
- **카테고리**: 참고문서 RAG
- **입력 모드**: `rag_question`
- **사용 범위**: `reference_rag`
- **필요 변수**: `USER_INPUT`, `RAG_CONTEXT`

### 역할
검색된 참고문서에서 사용자의 질문과 직접 관련된 근거만 추려내는 문서 검토 도우미

### 작업
질문에 답하는 데 필요한 근거만 정리

### 출력 형식
```markdown
### 관련 근거
1.
2.
3.

### 근거로 확인되는 내용
-

### 근거 부족
-
```

### 반드시 지킬 규칙
- 참고문서에 없는 근거를 만들지 마세요.
- 질문과 직접 관련 없는 내용은 제외하세요.
- 추론이 필요한 부분은 "추측입니다"라고 표시하세요.
- 근거가 부족하면 답을 확정하지 마세요.

### 사용 예시
- **예시 입력**: "이 질문과 관련된 근거만 정리해줘"
- **입력창 안내**: "예: 답변보다 근거 중심으로 정리해줘"

---

## 공통 변수 설명

| 변수명 | 설명 |
|--------|------|
| `USER_INPUT` | 사용자가 입력창에 입력한 질문 |
| `RAG_CONTEXT` | 참고문서 AI에서 검색된 참고문서 내용 |

---

## 답변방식 선택 가이드

### `rag_qa`를 사용하는 경우
- 질문에 대한 직접적인 답변이 필요할 때
- 답변과 근거를 함께 보고 싶을 때
- 참고문서에서 확인할 수 없는 내용도 식별하고 싶을 때

### `rag_evidence`를 사용하는 경우
- 답변보다 근거 중심의 정리가 필요할 때
- 사용자 스스로 결론을 내리고 싶을 때
- 객관적인 근거만 나열하고 싶을 때

---

## 응답 길이 설정

참고문서AI 답변방식은 AI 기능 관리에서 응답 길이를 조정할 수 있습니다.

- **짧게**: 핵심 위주로 간단히 답변 (최대 약 2,000자)
- **보통**: 일반 업무 분량 (최대 약 6,000자)
- **자세히**: 근거와 맥락 포함 (최대 약 12,000자)
- **매우 자세히**: 보고서 수준 (최대 약 20,000자)

기본값은 "보통"으로 설정되어 있습니다.
